WebADB

A host-side ADB implementation that runs in your browser over WebUSB — no native adb executable required.

Before you start

  1. Use a Chromium-based browser (Chrome, Edge, Brave, Opera) on desktop or Android. Firefox and Safari do not support WebUSB.
  2. On the phone: enable Developer options → USB debugging, then connect it by USB.
  3. Run adb kill-server first. The ADB USB interface is exclusive: if a native ADB server, Android Studio, or another browser tab already owns it, the browser cannot claim it.
Not connected

Could not claim the ADB interface. Make sure you ran adb kill-server and closed Android Studio / other tabs that may hold the device, then try again.

Configure InterProfileSharing across all users

Runs the full setup automatically: lists every user profile, finds the ones with digital.ventral.ips installed, grants android.permission.INTERACT_ACROSS_USERS to each, and force-stops the app so it restarts fresh.
