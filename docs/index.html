Inter Profile Sharing
Android 17+ Workaround

The Inter Profile Sharing app offers sharing information between Android User profiles in a way that doesn't require you to use cloud synchronization, messengers or USB sticks. To do so, it uses the localhost loopback (127.0.0.1) – a loophole that was never intended to work for cross-profile communications. With Android 17 released in June 2026 this loophole is now unavailable to 3rd party apps like Inter Profile Sharing by default. If you want to keep using it anyways you can use this page to grant the necessary permission to the App.

1

Before you start

  • First, install the Inter Profile Sharing App within all User Profiles you wish to share information between. The web tool grants the necessary permission to the app within each User Profile where it is installed. You can run it again later if you have a new User Profile with the app installed.
  • Make sure you are using a Chromium-based browser such as Google Chrome, Microsoft Edge, Brave, or Opera. Unfortunately, Firefox and Safari do not support WebUSB.
  • If you are an Android developer and you have an adb server running locally on this computer, run adb kill-server to ensure we can access the phone via WebUSB. If you don't know what adb is you can most likely just ignore this point.

2

Temporarily turn on Developer Mode on your Phone

Open your phone's Settings, go to About phone, scroll to the bottom and repeatedly tap Build number until it says "You are now a developer!"

3

Temporarily turn on USB Debugging on your Phone

Go back into the Settings overview and tap into System instead, scroll down to Advanced here and tap Developer options. Scroll to Debugging and turn on USB debugging.

4

Connect the Phone

While you're in the Profile of the Owner user, use a data-capable USB cable to connect your phone to this computer. Once done, click the Connect button below. The browser will then ask you to select a device. If your Phone is properly connected, you should be able to select it there.

Your phone will now ask you to authenticate the connection. For the tool to work you have to tap "Allow".

5

Granting the Permission

Once your phone is connected and authenticated, we will list your Phone's User Profiles and check which of them have the Inter Profile Sharing app installed. You can then confirm to grant the necessary permission to them and we'll restart the app to ensure it will take effect immediately.

6

Clean Up

You should now turn off the USB debugging and then the Use developer options toggle under Settings › System › Developer options. Keeping USB debugging turned on unnecessarily can be dangerous!
